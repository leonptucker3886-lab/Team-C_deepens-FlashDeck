# FlashDeck

Flashcards with spaced repetition. Make decks, add cards, and study only what's due. Target price: $4.99 one-time.

## How to run
Open `index.html` in a browser. No install or server. Data stays in your browser (localStorage). Deployed on Vercel as a static site.

## Features
- Create, study and delete decks
- Add cards one at a time or in bulk (`front | back` per line)
- SM-2 spaced repetition: grade Again / Hard / Good / Easy
- Due counts per deck, reviews today, daily study streak
- Dark mode
- JSON backup export/import
